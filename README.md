# 📊 Math Tables, Square & Cube App (1–100)

An Android educational app that displays multiplication tables, squares, and cubes from 1 to 100.  
This app helps students quickly learn and practice important math concepts.

---

## 🚀 Features

- 📈 Multiplication tables from 1 to 100
- 🔢 Square calculation (1–100)
- 🔺 Cube calculation (1–100)
- ⚡ Instant result display
- 📱 Clean and simple UI
- 🎯 Beginner-friendly educational tool

---

## 🛠️ Tech Stack

- Kotlin / Java
- Android Studio
- XML Layout

---

## 📂 How It Works

- User selects a number.
- App dynamically generates:
  - Multiplication table
  - Square of the number
  - Cube of the number
- Results update instantly on screen.
